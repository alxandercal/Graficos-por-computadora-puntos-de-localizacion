Estos codigos se realizaron como parte de mi tarea de graficos por computadora.\
Buscan solucionar tres problemas distintos ;
- La distancia minima entre dos puntos.
- Punto dentro de una region.
- Centroide de un poligono.


  Estos codigos se realizaron en python solo dependiendo de la libreria math.

**Consideraciones**\
  Estos código no cuentan con practicamente ninguna validacion por lo cual
  se recomienda solo utilizar numeros enteros y evitar colocar caracteres

  En el caso de el código de el punto mas lejano puede llegar a dar error en casos
  en que la distancia entre cualquiera de los vertices y el punto sea mayor al
  falso infinito de la funcion calc_dist().

  Ademas es necesario para evitar conflictos que cuando se coloquen los vertices de
  los poligonos estos se coloquen en sentido de las agujas del relog.
